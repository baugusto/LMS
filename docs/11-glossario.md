# Glossário

- **LMS**: Learning Management System.
- **Trilha (Learning Path)**: conjunto organizado de tópicos e recursos.
- **Tópico**: unidade de organização dentro de uma trilha.
- **Recurso**: item consumível (vídeo, PDF, link, quiz, etc.).
- **Quiz**: avaliação com perguntas objetivas/texto.
- **Partner/Parceiro**: usuário final do LMS.
- **Admin**: usuário com acesso de gestão.
- **Enrollment**: matrícula do usuário em uma trilha.
- **Progress**: estado de consumo de recursos.
- **VideoProgress**: progresso específico de vídeos.
- **Locale**: idioma/localização.
- **Translation**: override de tradução armazenada no banco.
